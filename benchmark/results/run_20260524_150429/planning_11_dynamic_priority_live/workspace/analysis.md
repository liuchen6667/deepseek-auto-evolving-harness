# 动态优先级调度分析

## 初始任务（T=0）：
- X: P0, value=8, 无依赖
- Z: P0, value=9, 无依赖
- M: P1, value=7, 无依赖
- Q: P1, value=5, 无依赖
- Y: P1, value=14, 依赖 Q
- N: P2, value=4, 无依赖

## 动态变化：
1. T+5: 如果 X 还没执行，X 的价值翻倍为 16
2. T+10: 新增 A: P0, value=12；B: P0, value=11；C: P0, value=3
3. T+15: Y 的依赖被取消，变为可执行
4. T+20: 如果 Z 还没执行，Z 降级为 P2 且价值变为 1

## 调度规则：
- 每个时间槽只能执行 1 个任务
- 先应用该时间点发生的动态变化，再选择该时间槽执行的任务
- 必须优先执行"当前可执行"的最高优先级任务
- 在同优先级内，最大化总价值

## 时间槽：
1. [0,5): T=0开始
2. [5,10): T=5开始，先应用T+5变化
3. [10,15): T=10开始，先应用T+10变化
4. [15,20): T=15开始，先应用T+15变化
5. [20,25): T=20开始，先应用T+20变化
