# 隐藏约束发现报告

## 发现的隐藏约束

### 1. 数据库连接池限制（最大10个连接）
- **来源**: system_code/db_config.py:15
- **对性能的影响**: 并发请求超过10个时，新的数据库请求需要等待连接释放，导致请求延迟增加，系统吞吐量受限。
- **优化建议**: 使用连接池监控，优化SQL查询减少连接持有时间；实现连接复用；考虑使用读写分离减少主库压力。

### 2. Redis缓存TTL只有60秒
- **来源**: system_code/cache_service.py:28
- **对性能的影响**: 缓存命中率低，频繁的缓存失效导致大量数据库查询，增加数据库负载和响应时间。
- **优化建议**: 根据数据访问模式设置差异化TTL：热点数据设置较长TTL（如300秒），冷数据保持短TTL；实现缓存预热机制。

### 3. 文件上传大小限制5MB
- **来源**: system_code/upload_controller.py:45
- **对性能的影响**: 大文件上传被拒绝，需要客户端分片上传，增加网络往返次数；服务器需要处理分片合并，增加CPU和I/O开销。
- **优化建议**: 实现客户端分片上传和服务器端分片合并；使用流式处理避免内存溢出；考虑使用CDN或对象存储服务。

### 4. API rate limit是100 req/min
- **来源**: system_code/middleware/rate_limit.py:22
- **对性能的影响**: 高并发场景下请求被限流，用户体验下降；系统无法充分利用硬件资源。
- **优化建议**: 实施分层限流策略：对重要API放宽限制，对资源消耗大的API加强限制；使用令牌桶算法平滑流量；考虑用户等级差异化限流。

### 5. 单个查询不能返回超过1000行
- **来源**: system_code/query_service.py:67
- **对性能的影响**: 大数据量查询需要分页，增加数据库查询次数；客户端需要处理分页逻辑，复杂度增加。
- **优化建议**: 实现高效的分页查询（使用游标分页而非OFFSET/LIMIT）；添加查询结果缓存；优化查询语句减少不必要的数据返回。
